# Java Practice Programs ☕💻

This repository contains my Java practice programs created while learning and improving my programming skills.

## Programs Included

* 🔤 **Vowel Program** – To identify and display vowels from a given string.
* 📊 **Grade Calculator** – To calculate the grade based on marks obtained in 5 subjects.
* 💰 **Simple Interest** – To calculate simple interest using the principal amount, time, and rate of interest.
* 🔡 **Character Print** – To display the characters of a given word using a character array.

## Purpose

This repository documents my Java learning journey and helps me practice basic programming concepts such as **strings, arrays, conditions, loops, and mathematical operations**.
